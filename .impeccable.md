## Design Context

### Users
People capturing web context for AI conversations, research and UI development. Kian requested a professional, complete capture workflow with clear export and privacy controls.

### Brand Personality
Precise, calm, capable. Plain language and honest coverage indicators build confidence.

### Aesthetic Direction
A compact editorial utility with purple accents (Kian's explicit preference), bundled Manrope typography and consistent Lucide SVGs. Fixed 460 × 400 popup with internal panel scrolling and consistent 20px padding. Set intrinsic width explicitly for Chrome's native action popup. Support light and dark themes. Avoid decoration that competes with captured content.

### Design Principles
- Capture first; keep secondary configuration out of the main flow.
- Give every action a clear label, keyboard access and visible focus.
- Make review and complete export easy; never imply unverified completeness.
- Explain when captured content leaves the browser.
- Keep assets local and the runtime dependency-free.
