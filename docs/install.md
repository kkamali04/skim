# Install Skim

Skim is currently an unpacked Chrome extension. It is not listed in the Chrome Web Store.

The latest version is a release candidate. Public ZIPs may be older previews. Clone the repository to test the latest source.

1. Download a ZIP from [Releases](https://github.com/kkamali04/skim/releases).
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
6. Pin Skim from Chrome's Extensions menu.

If you clone the repository, select its **`extension/` folder**, not the repository root.

Open a normal web page and click Skim. Keep the popup open until capture finishes, then paste with **Ctrl+V**. The shortcut is **Alt+Shift+P**.

After updating the files, click **Reload** on Skim's extension card. Refresh the page before capturing again.

Continue with [Use Skim](usage.md).
